# Frontend do VigIA

Interface web feita com React. Ela reúne o painel operacional, o mapa, as ocorrências, as viaturas e os alertas.

## Executar localmente

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

Com a API Laravel em execução na porta `8000`, acesse `http://127.0.0.1:5173`.

## Verificações

```powershell
npm run lint
npm run build
```
